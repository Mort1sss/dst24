# Таксопарк «ДСТ-24»

Пиксельная игра-менеджер: вы владелец таксопарка и решаете проблемы трёх отделов — «Подключение», «Автопарк» и «Сервис».

Играть: https://mort1sss.github.io/dst24/

- Кампания на 30 дней или бесконечный режим с целями
- Автосалон, база, персонал, проверки учредителей, конкуренты
- Прогресс сохраняется в браузере, а между устройствами переносится кодом сохранения (кнопка «Сохранение»)
