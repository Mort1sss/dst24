# Таксопарк «ДСТ-24»

Пиксельная игра-менеджер: вы владелец таксопарка и решаете проблемы трёх отделов — «Подключение», «Автопарк» и «Сервис».

Играть: https://mort1sss.github.io/dst24/

- Кампания на 30 дней или бесконечный режим с целями
- Автосалон, база, персонал, проверки учредителей, конкуренты
- Прогресс сохраняется в браузере; с аккаунтом (меню → «Онлайн») — ещё и в облаке, между устройствами
- Онлайн: общая таблица рекордов, соревнование недели, «Город» — переманить водителя или сделать подарок другу
- Без сети игра работает как раньше; настройка сервера — `supabase/README.md`
