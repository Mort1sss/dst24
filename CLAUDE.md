# Таксопарк «ДСТ-24»

Пиксельная пошаговая игра-менеджер таксопарка для браузера и телефона (PWA).
Играть: https://mort1sss.github.io/dst24/ — публикуется через GitHub Pages из ветки `main`.

## Структура

Сборки, зависимостей и сервера нет: всё работает прямо в браузере.

| Файл | Что внутри |
|---|---|
| `index.html` | Вся игра: CSS, разметка, данные, логика, отрисовка, звук |
| `sw.js` | Офлайн-режим: сначала сеть, без неё — кэш `dst24-vN` |
| `manifest.webmanifest` | Название, цвета и иконки для установки как приложения |
| `icon-192.png`, `icon-512.png` | Иконки |

`index.html` разбит на главы с заголовками `/* ===== ГЛАВА ===== */` и подразделами `/* ---- раздел ---- */`. Искать нужное место удобнее всего по этим заголовкам:

- `ДАННЫЕ` — справочники: машины, события и дилеммы, начальники, районы, газета
- `СОСТОЯНИЕ` — объект `S` (текущая партия) и `G` (общие настройки), `save()` / `load()`
- `НОВАЯ ИГРА`, `СОБЫТИЯ ДНЯ`, `КОНЕЦ ДНЯ`, `УТРО` — основной игровой цикл
- `МИНИ-ИГРЫ ПРОВЕРОК` и `мини-игры на линии`, `диспетчер` — всё, что идёт в реальном времени
- `ОТРИСОВКА ИНТЕРФЕЙСА` — `render()` и обработчики кнопок
- `ПИКСЕЛЬ-АРТ`, `сцена` — рисование на `<canvas>`
- `ЗВУК`, `ЗАСТАВКА`, `СТАРТ`

## Данные и сохранения

- Партия хранится в `localStorage` под ключом `dst24-save-v1`, общие настройки — под `dst24-global-v1`.
- Новое поле состояния добавлять в `blankState()`: `fixState()` подставит его в старые сохранения, и они не сломаются.
- Ключи сохранений не переименовывать: у игроков пропадёт прогресс.
- Код сохранения (`DST24Z.…`) — это сжатый JSON состояния. Формат должен оставаться совместимым со старыми кодами.

## Как писать код

Пишите так же, как написан остальной код:

- Только чистый JavaScript, HTML и CSS в `index.html`. Никаких библиотек, фреймворков и сборщиков.
- Плотный стиль: короткие функции в одну-две строки, стрелочные функции, короткие имена для частых вещей (`S`, `G`, `$`, `rub`, `rand`).
- Комментарии на русском и только там, где без них непонятно. Новый раздел начинать с заголовка `/* ---- название ---- */`.
- Весь текст для игрока на русском, в тоне игры. Пользовательские строки вставлять в HTML через `esc()`.
- Обращения к `localStorage` и аудио оборачивать в `try{…}catch(e){}`: игра не должна падать в приватном режиме.
- Цвета брать из CSS-переменных (`--night`, `--taxi`, `--panel`, …), пиксельный стиль сохранять.
- Мини-игры: кадры запускать через `mgRAF()`, а не напрямую через `requestAnimationFrame`, таймеры проверять на `paused`, в конце вызывать `mgStop()`. Тогда пауза работает автоматически.
- Учитывать телефон: ширина от 375 px, без горизонтальной прокрутки, крупные кнопки.

## Выпуск обновления

1. Работать в отдельной ветке, в `main` сливать только проверенное.
2. Проверить локально: `python3 -m http.server 8024` и открыть http://localhost:8024 (в том числе в мобильной ширине).
3. При каждом выпуске поднимать версию кэша в `sw.js` (`dst24-v10` → `dst24-v11`), чтобы установленная игра обновилась.
4. Коммиты на русском. Крупные выпуски называть «Обновление N: что нового через запятую».
